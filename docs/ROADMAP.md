# Roadmap Caliinda

Работаем по этапам сверху вниз. Один пункт = один коммит (или небольшая серия).
Отмечаем `[x]` по мере выполнения. Дизайн — по `docs/DESIGN.md`.

## Этап 1 — Баги

- [x] **1.1 DatePicker и часовой пояс.** M3 `DatePicker` работает с полуночью UTC, а код
  передаёт/читает millis через пояс пользователя: в UTC+ подсвечивается вчерашний день,
  в UTC− выбранная дата сохраняется на день раньше. Перевести на `ZoneOffset.UTC`:
  `CalendarScreen.kt` (initialSelectedDateMillis, onConfirm),
  `HandlePickerLogic.kt` (StartDate, EndDate + selectableDates, RecurrenceEnd).
  Вынести хелперы `LocalDate.toPickerMillis()` / `Long.fromPickerMillis()`.
- [x] **1.2 «Сегодня» после полуночи.** `CalendarScreen.kt` (`remember { LocalDate.now() }`),
  `ProjectEventsPage.kt` (flow проектов создаётся один раз), `CalendarViewModel`/
  `EventUiModelMapper`/`CalendarDateTitle` (`LocalDate.now()` в системном поясе).
  Сделать единый поток «сегодня» в поясе из настроек (от `TimeTicker`), пересоздавать
  зависимые flow при смене дня.
- [x] **1.3 Время по умолчанию около полуночи.** `CreateEventScreen.kt`: при `now + 1h`
  через полночь стартовая дата должна сдвигаться на следующий день.
- [x] **1.4 Пикер даты в шапке** открывается со старой датой — синхронизировать
  `datePickerState` с `currentVisibleDate` при открытии; убрать пустую строку
  `datePickerState.selectableDates`.
- [x] **1.5 «days left».** Округление вверх, «последний день» вместо 0, вынести в `plurals`.
- [x] **1.6 Локализация.** Строки в коде → ресурсы: «Syncing calendars…», «(No title)»,
  «Edit», «Cancel», «OK», «Regular events», `contentDescription` в AppBar/BottomBar/карточках.
- [x] **1.7 Мусор.** `app/release/` в `.gitignore`; удалить/доделать неиспользуемое:
  `WeekState`, пустой `ManagementScreen`/`AppMode.MANAGEMENT`, `validationError`/
  `generalError` в форме, дублирующий `requestEventDetails` в `EventManagementViewModel`.

## Этап 4 — Проекты по месяцам

Решение: остаются карточки проектов (их стиль — часть приложения), таймлайн с капсулами
попробовали и отказались — выбивается из стилистики.

- [x] **4.1** Репозиторий: `getMonthProjectsFlow(YearMonth)` — многодневные события, пересекающие
  месяц (включая прошлые), и `getProjectsFlowForDate` для страницы дня.
- [x] **4.2** Экран проектов — вертикальный пейджер: один свайп = один месяц, вниз — будущее, вверх —
  история. Месяц в шапке, «сегодня» возвращает к текущему месяцу.
- [x] **4.5** На странице дня — тонкие ленты идущих проектов («день 3 из 10», волнистый прогресс).
- [ ] **4.0** Высота карточки проекта: у ещё не начавшегося проекта она максимальная; подпись
  многодневных — только даты, без времени. (По желанию — дизайн карточек пока не трогаем.)
