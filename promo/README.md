# Промо-ролики Caliinda

Ролики на [Remotion](https://www.remotion.dev): каждый кадр — React-компонент, анимация — от номера
кадра. Цвета считаются тем же алгоритмом Material You, что и на телефоне.

```bash
npm run studio            # редактор с превью
npm run render:variants   # все варианты, en + ru → out/variants/
node scripts/stills.mjs LongRu /tmp/stills 120 186 320   # отдельные кадры для проверки
```

## Ролики

| Composition | Файл | Идея |
|---|---|---|
| `Promo`, `PromoWide` | `Promo.tsx`, `DayScene.tsx` | Общий ролик: лента дня, темы, виджеты, финал |
| `Swipe` | `Swipe.tsx` | Свайп — и завтра: карточки отстают на пружинках |
| `Chips` | `Chips.tsx` | Три события подряд чипами, каждое быстрее |
| `Long` | `Long.tsx` | Месяц раздувается пузырём и лопается → долгие события на своей странице |
| `Colors` | `Colors.tsx` | Каждое открытие — новые обои и новые цвета, светлые и тёмные |

У каждого есть пара `…Ru`. Общие детали — `kit.tsx` (карточка, шапка, палец, подписи, физика
«веса»), финал — `End.tsx`, схемы — `schemes.ts`.

## Принципы

То, ради чего приложение делалось и что ролик должен передать, — **ощущение**, а не список функций.

- **Живость важнее показа функций.** Нужна физическая метафора и драматургия: месяц надувается
  пузырём и лопается — «БАХ!» — а потом тишина и порядок. Просто «вот экран, вот кнопка» — скучно.
- **Карточки — реальные предметы.** У них есть вес и пружина: при листании отстают и догоняют
  с перелётом (SpringyScroll), падают и приземляются с отскоком, при посадке сплющиваются, соседи
  вздрагивают. Ничего не появляется просто так — всё прилетает, пружинит, толкает соседей.
- **Текущее событие поднимается к зрителю.** Как в приложении: третичный цвет, узкий наклонный
  шрифт, плотная тень (4/5/2 dp, 50 %) и подъём 12 dp — карточка висит над остальными. В ролике
  она ещё чуть крупнее, а камера подъезжает к ней, чтобы был виден ползущий червячок прогресса.
  Взгляд должен сразу цепляться за «сейчас».
- **Цвета — сочные.** Бледный Tonal Spot выглядит блекло. Для светлых сцен — насыщенный цвет как
  есть (`JUICY`: Content из `#FFD600` — карточки ядовито-жёлтые, текущие лаймовые) или тёплый
  «Яркий» (`WARM`). Динамические цвета — главная красота, их стоит показывать.
- **Светлая тема — по умолчанию.** Порядок и чистота — это белый. Тёмную показываем как
  разнообразие (ролик о цветах, смена тем), но не как основную.
- **Пружины, а не плавные кривые.** Почти всё — `spring` с лёгким перелётом. Камера — резкий
  разгон и мягкая посадка.
- **Слова.** Не «проекты», а «всё, что дольше дня» / "anything longer than a day". Подписи
  короткие, слова выпрыгивают по одному.
- **Честность.** Экраны повторяют приложение: размеры в dp (`DP = 1080 / 411`), высоты карточек
  по той же сигмоиде, подписи чипов из `strings.xml`. Чего в приложении нет (например, подъёма у
  текущих долгих событий), в ролике тоже нет.
